## Publication policy

Project pages may carry a `repository` link only when the linked source
repository has already been published publicly. Source code that is internal,
confidential or not yet released must never be linked from the portfolio.

## Editing

Each project lives in `projects/<slug>.md` with YAML front matter. Keep the
front matter valid YAML.
